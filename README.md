# İş Hukuku · Çalışma Rehberi

İş Hukuku ders kitabının (**Levent Akın & Hande Bahar Aykaç**, İş Hukuku, Ankara 2025) tamamı için hazırlanmış, tek sayfalık interaktif çalışma sitesi.

🔗 **Canlı:** https://hukuk-calisma.vercel.app

## İçerik
- **§1–§54** — kitabın bütün paragrafları
- **506 soru–cevap kartı** (tıkla → cevabı gör)
- Her bölümde: sadeleştirilmiş notlar, kanun künyeleri (İK./BK./m.), kilit & dikkat kutuları, anahtar kavramlar

## Özellikler
- Aydınlık / karanlık tema
- § navigasyonu ve okuma ilerleme çubuğu
- Bölüm bazında "okundu" takibi (tarayıcıda saklanır)
- Mobil uyumlu, yazdırılabilir
- Tek dosya, bağımsız (harici bağımlılık yok)

## Yapı
- `index.html` — sitenin tamamı (inline CSS + JS)
- `vercel.json` — Vercel yapılandırması

## Geliştirme / Yayınlama
Statik bir sayfa; `index.html`'i tarayıcıda açman yeterli. Yayına almak için:

```bash
vercel deploy --prod
```

## Not
Notlar öğrenme amaçlıdır ve taranmış kitabın OCR'ından üretilmiştir; sınav/uygulama öncesinde kaynak kitapla karşılaştırın. Kitabın telif hakları yazarlarına aittir.
